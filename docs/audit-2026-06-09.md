## 1. 任务生命周期管理与编排引擎

### P1 — 功能断裂

- **`PlanExecuteStrategy` 完全损坏** — `engine/loop_strategies/plan_execute.py:23`，`_plan_steps` 初始化后从未被填充，`execute` 阶段因列表始终为空而直接跳到 `summarize`。该策略从未实际执行任何计划步骤
- **`DefaultErrorPolicy` 实例化后从未连接到任何组件** — `base.py:262-267`，构造完即丢弃，引擎的 `_handle_error` 完全不知道它的存在。导入和构造都是死代码
- **`agent_mode` 始终为空字符串** — `control_plane.py:360`，`ConcurrentToolExecutor.execute()` 传入 `agent_mode=""`，导致 `if agent_mode:` 分支永远不触发，per-call metadata 注入机制完全失效
- **`_fire_and_drain` 存在 asyncio.Event 线程安全问题** — `control_plane.py:396-418`，blocking plugin 在非事件循环线程中调用 `ctx.emit()` → `asyncio.Event.set()`，线程不安全操作可能导致事件丢失或引擎挂起

### P2 — 工程缺陷

- **MCP 解析失败被静默吞没** — `control_plane.py:245-247`，`except Exception: pass`，返回空工具列表
- **会话异常无清理** — `chat()`/`astream()` 抛异常时 session 保持 active，`_active_sessions` 泄漏

- **`chat()` 与 `astream()` 大量重复代码** — `base.py:750-801` 与 `803-851`，状态构建和会话解析逻辑完全重复
- **`error_policy` 构造后立即丢弃** — `base.py:262-267`，`ControlPlane` 有自己的 `_handle_error`，两者互不知晓
- **`TurnContext` 数据类从未被实例化** — `core/state.py:20-29`，仅在 `retry.py:33` 的无人调用的方法签名中存在
- **`LoopStrategy` 无显式实现声明** — `ReActStrategy` 和 `PlanExecuteStrategy` 都不继承 `LoopStrategy` Protocol
- **隐式状态机** — `control_plane.py:72-222`，执行循环生命周期完全由嵌套循环和 `yield` 点隐含，无状态枚举或转换表
