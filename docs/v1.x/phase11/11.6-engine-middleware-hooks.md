# Phase 11 / 11.6 — Engine Middleware 钩子层

> **Task**: 在 Engine 添加 `before_model_call` / `modify_request` / `after_model_call` 钩子层。
> **Gap addressed**: G-02（Middleware 包装层 — wrap_model_call / modify_request / before_agent）
> **Source**: `docs/v1.x/phase10/99-gap-summary-recommendations.md` §3 G-02
> **Reference**: DeepAgents `libs/deepagents/deepagents/middleware/`（18 个 middleware）
> **Status**: 📝 Doc — awaiting user Gitee 精校

---

## 1. Motivation

Phase 10 深度对标发现 ARFV1 **没有 request-mutation 钩子**：
- `CheckpointRule` 是**声明式钩子**（fire-and-forget），Middleware 是**包装式钩子**（可修改请求）
- Middleware 可在 model_call 之前**改写 prompt 注入**、**改写 tool list**
- CheckpointRule 只能插入消息，不能改写已有消息 / tools

DeepAgents 18 个 middleware 都基于 `wrap_model_call` / `before_agent` / `modify_request`。

**本任务目标**：在 ARFV1 中建立等价的 `Middleware` trait，让 FilesystemMiddleware / SummarizationMiddleware / MemoryMiddleware / RubricMiddleware 等可基于此实现。

## 3. 完整代码

### 3.1 `crates/arf-core/src/middleware.rs`（新建）

```rust
//! Middleware trait — request-mutation hooks for the Engine ReAct loop.
//!
//! Distinct from `CheckpointRule`:
//! - CheckpointRule is **declarative** (fire-and-forget, append messages)
//! - Middleware is **wrapping** (mutate the outgoing ModelRequest in place)
//!
//! All hooks are async to allow I/O during middleware execution.

use async_trait::async_trait;
use serde::{Deserialize, Serialize};
use serde_json::Value;

use crate::message::ModelMessage;
use crate::tool::ToolSpec;
use crate::State;

/// Mutable context for `before_model_call`.
///
/// Middleware can:
/// - Append/prepend messages
/// - Mutate system_prompt_suffix
/// - Add or remove tools
/// - Set abort = true to short-circuit the model call
pub struct ModelRequest {
    /// The full message list (system + memory + skills + conversation).
    pub messages: Vec<ModelMessage>,
    /// Suffix appended to system prompt (after the template).
    pub system_prompt_suffix: String,
    /// Tools visible to the model in this turn.
    pub tools: Vec<ToolSpec>,
    /// Set to `Some(reason)` to abort the model call (no API request made).
    pub abort: Option<String>,
}

impl ModelRequest {
    pub fn new(messages: Vec<ModelMessage>, tools: Vec<ToolSpec>) -> Self {
        Self {
            messages,
            system_prompt_suffix: String::new(),
            tools,
            abort: None,
        }
    }

    /// Append a system message at the end of the existing system messages
    /// (or as the first message if none exist).
    pub fn append_system(&mut self, content: impl Into<String>) {
        // Find last system index; insert after it. If none, prepend.
        let last_sys = self
            .messages
            .iter()
            .rposition(|m| m.role == "system")
            .map(|i| i + 1)
            .unwrap_or(0);
        self.messages
            .insert(last_sys, ModelMessage::new("system", content.into()));
    }

    /// Append to the system_prompt_suffix (concatenated at send time).
    pub fn extend_system_suffix(&mut self, content: impl Into<String>) {
        if !self.system_prompt_suffix.is_empty() {
            self.system_prompt_suffix.push('\n');
        }
        self.system_prompt_suffix.push_str(&content.into());
    }

    /// Add a tool to the model's visible tool list (de-duplicated by name).
    pub fn add_tool(&mut self, tool: ToolSpec) {
        if !self.tools.iter().any(|t| t.name == tool.name) {
            self.tools.push(tool);
        }
    }

    /// Remove a tool from the visible tool list.
    pub fn remove_tool(&mut self, name: &str) {
        self.tools.retain(|t| t.name != name);
    }
}

/// `Middleware` trait — request-mutation hooks in the ReAct loop.
///
/// Implementations are stored as `Vec<Arc<dyn Middleware>>` in
/// `EngineConfig.middlewares` and run in order during each model call.
#[async_trait]
pub trait Middleware: Send + Sync {
    /// Identifier for logging / debugging.
    fn name(&self) -> &str;

    /// Called once at agent startup, before any round. Use for one-shot
    /// setup (load files, register tools, etc.).
    async fn before_agent(&self, state: &State) {}

    /// Called before each `ModelCall` is sent. Mutates `ctx` in place.
    ///
    /// This is the primary hook for FilesystemMiddleware / MemoryMiddleware
    /// / SummarizationMiddleware — they inject tools, append system
    /// context, or summarize conversation here.
    async fn before_model_call(&self, ctx: &mut ModelRequest, state: &State) {}

    /// Called after the model responds. Use for response inspection,
    /// rubric scoring, log enrichment. Default: no-op.
    async fn after_model_call(&self, state: &State, response: &Value) {}

    /// Called once at agent shutdown (after final round). Default: no-op.
    async fn after_agent(&self, state: &State, final_output: &str) {}
}
```

### 3.4 `crates/arf-engine/src/engine.rs` 集成

在 `do_model_turn` 中（替换 line 805-833 之间的 prefix assembly + ModelCall 构建）：

```rust
async fn do_model_turn(
    &mut self,
    state: &mut State,
    cancel: CancellationToken,
) -> Result<(String, Vec<ToolCall>), RunError> {
    state.inc_turn();

    // Build initial messages (Phase 6 layered prefix).
    let skills_text = self.registry.skills_text(&self.primary_bus);
    let mut messages: Vec<ModelMessage> = Vec::with_capacity(
        2 + self.initial_memory.len() + state.messages.len(),
    );
    messages.push(ModelMessage::new("system", &self.system_prompt_template));
    for m in &self.initial_memory {
        messages.push(ModelMessage::new("system", m));
    }
    if !skills_text.is_empty() {
        messages.push(ModelMessage::new("system", &skills_text));
    }
    messages.extend(state.messages.iter().cloned());

    let tools = self.registry.tools_for_model(&self.primary_bus);

    // === Phase 11 G-02: Middleware chain ===
    let mut ctx = ModelRequest::new(messages, tools);

    // Run middlewares in order. Each can mutate `ctx`.
    for mw in &self.config.engine.middlewares {
        mw.before_model_call(&mut ctx, state).await;
        if let Some(reason) = &ctx.abort {
            // Middleware short-circuited the call. Return empty response.
            tracing::info!(middleware = mw.name(), reason, "model_call aborted by middleware");
            return Ok((String::new(), vec![]));
        }
    }

    // Apply system_prompt_suffix.
    if !ctx.system_prompt_suffix.is_empty() {
        // Insert suffix as a new system message at the end of system messages.
        ctx.append_system(&ctx.system_prompt_suffix.clone());
    }

    // === Build ModelCall ===
    let model_params = arf_core::CoreModelParams {
        thinking_enabled: self.config.model.thinking_enabled,
        temperature: self.config.model.temperature,
        max_tokens: self.config.model.max_output_tokens,
        extra: serde_json::Value::Object(Default::default()),
    };
    let model_call = ModelCall::new(ctx.messages)
        .with_tools(ctx.tools)
        .with_model_params(model_params);

    let cid = model_call.correlation_id;
    let target = self.registry.model_target();
    let msg = Message::with_from_bus(
        model_call.msg_type(),
        self.agent_id.clone(),
        vec![target],
        model_call.payload(),
        self.handle.primary_bus_id(),
    );

    let response = self.send_and_await(state, cid, msg, cancel).await?;

    // === After-model-call middleware chain ===
    for mw in &self.config.engine.middlewares {
        mw.after_model_call(state, &response.payload).await;
    }

    // ... 现有 response parsing ...
}
```

### 3.5 `crates/arf-engine/src/engine.rs` 中 `before_agent` / `after_agent`

在 `Engine::run` 开始时调用 `before_agent`：

pub async fn run(
    &mut self,
    state: &mut State,
    user_input: String,
    cancel: CancellationToken,
) -> Result<String, RunError> {
    // ... existing setup ...
    for mw in &self.config.engine.middlewares {
        mw.before_agent(state).await;
    }
    let result = self.run_inner(state, user_input, cancel).await;
    // ... existing finalization ...
    if let Ok(ref final_output) = result {
        for mw in &self.config.engine.middlewares {
            mw.after_agent(state, final_output).await;
        }
    }
    result
}

## 4. 逐行解释

### 4.1 `ModelRequest` 可变上下文

```rust
pub struct ModelRequest {
    pub messages: Vec<ModelMessage>,
    pub system_prompt_suffix: String,
    pub tools: Vec<ToolSpec>,
    pub abort: Option<String>,
}
```

- `messages` — 中间件可以**追加/重排**
- `system_prompt_suffix` — 单独的字段，避免 middleware 之间相互覆盖
- `tools` — 动态增删（per-request 裁剪的关键）
- `abort: Option<String>` — 中间件可以**短路**（如配额检查失败）

### 4.2 `Middleware` trait 默认 no-op

```rust
async fn before_agent(&self, state: &State) {}
```

每个 hook 都有默认实现，避免空实现噪音。

### 4.3 中间件链顺序

```rust
for mw in &self.config.engine.middlewares {
    mw.before_model_call(&mut ctx, state).await;
}
```

**顺序执行**：FilesystemMiddleware 在 MemoryMiddleware 之前注册，那么 FilesystemMiddleware 先注入工具，MemoryMiddleware 看到完整 tool list。这是 ARF 文档化的扩展约定。

### 4.4 abort 短路

```rust
if let Some(reason) = &ctx.abort {
    return Ok((String::new(), vec![]));
}
```

Middleware 可以拒绝发送模型请求（节省 token、避免越权）。返回空响应让 caller 继续 ReAct 循环。

### 4.5 与 CheckpointRule 的差异

| 维度 | CheckpointRule | Middleware |
|------|----------------|-----------|
| 触发方式 | 声明式（when + build） | 包装式（直接调用） |
| 修改 messages | 只能追加 | 可改任意字段 |
| 修改 tools | 不能 | **能**（per-request 可见性裁剪） |
| 短路 | 不能 | **能**（abort） |
| 异步 I/O | 通过 ActionMessage | 直接 async fn |

两者**并存**——CheckpointRule 适合"每 N 轮插入 memory 提取请求"，Middleware 适合"每次都改写 prompt"。

## 6. 与 DeepAgents Middleware 的差异

| 维度 | DeepAgents | ARFV1 | 原因 |
|------|------------|-------|------|
| Hook 风格 | `wrap_model_call` decorator | `before_model_call` mutation | ARF async-first，mutation 更直接 |
| 中间件状态 | dict-like config | `Arc<dyn Middleware>` | Rust trait-based DI |
| abort | raise exception | `Option<String>` abort 字段 | 类型化错误 |
| 工具裁剪 | 不支持 | **支持**（per-request） | ARF G-10 需求 |
| 默认实现 | 全是 raise NotImplementedError | 全是 no-op default | 减少样板 |

---

## 7. 不破坏 ARFV1 现有优势

1. **CheckpointRule 共存** — Middleware 是新维度，不替换
2. **Bus 多 runtime** — Middleware 在 Engine 内运行，不影响 bus 拓扑
3. **Protocol DI** — `Arc<dyn Middleware>` 保持 trait-based DI
4. **异步优先** — 所有 hooks 都是 async
