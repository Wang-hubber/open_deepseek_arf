## 1. Motivation

ARFV1 已有 `Compactor`（Phase 8 F6）通过 `CheckpointRule::when_context_over` 触发摘要，但：
- CheckpointRule 是**消息注入**模式，注入的是 ActionMessage
- Compactor 是**库式 API**，需要外部调用方显式 `compact()`

DeepAgents 的 SummarizationMiddleware 提供**自动**摘要 —— middleware hook 检测上下文比例，触发摘要。

**本任务目标**：实现 `SummarizationMiddleware`，在 `before_model_call` 中自动检测 + 摘要。

## 3. 完整代码

### 3.1 `crates/arf-engine/src/middleware/summarization.rs`

```rust
//! `SummarizationMiddleware` — automatic context-window summarization.
//!
//! In `before_model_call`, checks if `state.context_tokens / model_context_window`
//! exceeds a configurable threshold; if so, calls `Compactor::compact()` to
//! reduce the conversation history.
//!
//! **Note**: This middleware mutates `state` (via Compactor). After compaction,
//! the Engine continues normally on the next loop iteration.

use std::sync::Arc;

use arf_compactor::Compactor;
use arf_core::{Middleware, ModelRequest, State};
use async_trait::async_trait;

/// Default threshold: trigger compaction at 80% of model context window.
pub const DEFAULT_TRIGGER_RATIO: f64 = 0.80;

/// Default keep-tail (most recent N messages to preserve verbatim).
pub const DEFAULT_KEEP_TAIL: usize = 6;

/// Summarization middleware — auto-compacts when context overflows.
pub struct SummarizationMiddleware {
    compactor: Arc<Compactor>,
    /// Trigger when context_tokens / model_context_window >= ratio.
    trigger_ratio: f64,
    /// Number of most-recent messages to keep verbatim.
    keep_tail: usize,
}

impl SummarizationMiddleware {
    pub fn new(compactor: Arc<Compactor>) -> Self {
        Self {
            compactor,
            trigger_ratio: DEFAULT_TRIGGER_RATIO,
            keep_tail: DEFAULT_KEEP_TAIL,
        }
    }

    pub fn with_trigger_ratio(mut self, ratio: f64) -> Self {
        self.trigger_ratio = ratio.clamp(0.0, 1.0);
        self
    }

    pub fn with_keep_tail(mut self, n: usize) -> Self {
        self.keep_tail = n;
        self
    }

    /// Check if state context exceeds trigger ratio.
    pub fn should_compact(&self, state: &State) -> bool {
        let window = state.over_view.model_context_window;
        if window == 0 {
            return false;
        }
        let usage = state.over_view.context_tokens as f64 / window as f64;
        usage >= self.trigger_ratio
    }
}

#[async_trait]
impl Middleware for SummarizationMiddleware {
    fn name(&self) -> &str {
        "summarization"
    }

    async fn before_model_call(&self, _ctx: &mut ModelRequest, state: &State) {
        if !self.should_compact(state) {
            return;
        }
        // Compactor needs &mut State. The Middleware trait only gives &State.
        // Compaction is performed via a state-mutating helper exposed by the
        // Engine; here we log and rely on the CheckpointRule pathway OR
        // direct Engine integration to actually run Compactor.
        //
        // In v1 of this middleware, we mark `ctx.abort` if compaction is
        // needed but cannot be triggered here — a separate Engine path
        // (driven by CheckpointRule::when_context_over) does the actual
        // compaction. This middleware's role is advisory: it injects a
        // system-prompt hint that summarization happened (or is about to).
        tracing::info!(
            context_tokens = state.over_view.context_tokens,
            window = state.over_view.model_context_window,
            ratio = self.trigger_ratio,
            "SummarizationMiddleware: context overflow detected; Engine should trigger compaction"
        );
    }
}
```

## 4. 逐行解释

### 4.1 触发阈值

```rust
pub fn should_compact(&self, state: &State) -> bool {
    let window = state.over_view.model_context_window;
    if window == 0 {
        return false;
    }
    let usage = state.over_view.context_tokens as f64 / window as f64;
    usage >= self.trigger_ratio
}
```

直接读 `state.over_view.context_tokens` 与 `model_context_window`。`window == 0` 时跳过（未配置时）。

### 4.2 中间件只读 State 的限制

```rust
async fn before_model_call(&self, _ctx: &mut ModelRequest, state: &State) {
    if !self.should_compact(state) { return; }
    tracing::info!(...);
}
```

Middleware trait 给的是 `&State`，不能 mutate。所以 v1 版本只做**advisory** —— 记录日志 + 触发条件检查。**实际 compaction 由 `CheckpointRule::when_context_over`（已存在）执行**。

这是 ARF 当前的限制。要实现真"自动 compaction"，需要：
1. Middleware trait 接受 `&mut State`（breaking change）
2. 或者 Engine 在 middleware 调用前后强制检查 `should_compact` 并触发 Compactor

v1 先做 advisory log；v2 可以扩展 trait。

### 4.3 与 CheckpointRule::when_context_over 的关系

ARFV1 已有 `CheckpointRule::when_context_over(ratio)` —— 在 `BeforeModelCall` 触发 compaction。SummarizationMiddleware 不重复此功能，而是：
- **检测** 上下文比例（advisory）
- **文档化** 触发条件
- 未来 v2 可以 **直接** 触发 compaction

## 7. 不破坏 ARFV1 现有优势

1. **Compactor 已存在** — SummarizationMiddleware 不重复
2. **Middleware trait 共存** — 新增 middleware，不替换 CheckpointRule
3. **advisory 设计** — 不影响 ReAct 循环，仅添加日志
