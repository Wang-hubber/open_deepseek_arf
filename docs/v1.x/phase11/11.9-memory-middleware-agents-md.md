# Phase 11 / 11.9 — `MemoryMiddleware` + AGENTS.md 加载

> **Task**: 实现 `MemoryMiddleware` —— 从 backend 加载 `AGENTS.md` / 持久 memory 注入 system prompt。
> **Gap addressed**: G-11 (AGENTS.md on-demand memory loading)
> **Source**: `docs/v1.x/phase10/99-gap-summary-recommendations.md` §3 G-11
> **Reference**: DeepAgents `MemoryMiddleware` —— `libs/deepagents/deepagents/middleware/memory.py`
> **Status**: 📝 Doc — awaiting user Gitee 精校

---

## 1. Motivation

DeepAgents 引入 AGENTS.md 作为**渐进披露**的 skill/agent 配置文件 —— 模型按需读取，避免一次性灌入所有 skills。

ARFV1 当前**没有 on-demand memory 加载**：
- `initial_memory` 在 EngineBuilder 时一次性读入
- AGENTS.md / 自定义 memory 文件不感知

**本任务目标**：实现 `MemoryMiddleware`，从 backend 读取 AGENTS.md（和可选 memory 文件），按需注入 system prompt。

## 2. Scope

### ✅ In scope

1. `MemoryMiddleware` 实现 `Middleware` trait
2. 在 `before_agent` 钩子中：
   - 从 backend 读取 `AGENTS.md`（root path `/AGENTS.md`）
   - 注入到 system prompt

   - 可选：注入"memory is loaded"提示，让模型知道

   - 可选：保存 memory 回 backend（v1 留空）

- 持久 memory 写回（→ G-30 后续）

## 3. 完整代码

### 3.1 `crates/arf-engine/src/middleware/memory.rs`

```rust
//! `MemoryMiddleware` — load AGENTS.md and persistent memory into system prompt.
//!
//! Reads `AGENTS.md` (or configured path) from a backend at agent startup
//! and injects the contents into the system prompt. The backend can be any
//! `BackendProtocol` — typically `FilesystemBackend` rooted at the project
//! directory, or `StateBackend` for testing.

use std::sync::Arc;

use arf_backend::{BackendPath, BackendProtocol};
use arf_core::{Middleware, ModelRequest, State};
use async_trait::async_trait;

/// Default path for AGENTS.md inside the backend.
pub const DEFAULT_MEMORY_PATH: &str = "/AGENTS.md";

/// Header prepended to the loaded AGENTS.md content in the system prompt.
pub const MEMORY_HEADER: &str = "\n\n# AGENTS.md (Persistent Memory)\n\n";

/// Memory middleware — loads AGENTS.md from backend.
pub struct MemoryMiddleware {
    backend: Arc<dyn BackendProtocol>,
    /// Backend path to the memory file.
    memory_path: BackendPath,
    /// Header to prepend to loaded content.
    header: String,
    /// If true, log a warning when memory file is missing (default: false).
    warn_if_missing: bool,
}

impl MemoryMiddleware {
    /// Create with default memory path (`/AGENTS.md`).
    pub fn new(backend: Arc<dyn BackendProtocol>) -> Self {
        Self {
            backend,
            memory_path: BackendPath::new(DEFAULT_MEMORY_PATH)
                .expect("static path is valid"),
            header: MEMORY_HEADER.to_string(),
            warn_if_missing: false,
        }
    }

    /// Set a custom memory path.
    pub fn with_memory_path(mut self, path: BackendPath) -> Self {
        self.memory_path = path;
        self
    }

    /// Set a custom header (e.g., to identify the source).
    pub fn with_header(mut self, header: impl Into<String>) -> Self {
        self.header = header.into();
        self
    }

    /// Enable warnings on missing memory file.
    pub fn warn_on_missing(mut self) -> Self {
        self.warn_if_missing = true;
        self
    }

    /// Borrow the wrapped backend.
    pub fn backend(&self) -> &Arc<dyn BackendProtocol> {
        &self.backend
    }

    /// Read the memory file from the backend. Returns `Ok(None)` if the
    /// file doesn't exist (per design choice for v1).
    pub async fn load_memory(&self) -> Result<Option<String>, arf_backend::BackendError> {
        let result = self.backend.read(&self.memory_path, 0, 0).await?;
        if result.error.is_some() {
            return Ok(None);
        }
        let data = result.file_data;
        Ok(data.map(|d| d.content))
    }
}

#[async_trait]
impl Middleware for MemoryMiddleware {
    fn name(&self) -> &str {
        "memory"
    }

    async fn before_agent(&self, state: &State) {
        match self.load_memory().await {
            Ok(Some(content)) => {
                tracing::info!(
                    path = %self.memory_path,
                    bytes = content.len(),
                    "MemoryMiddleware: loaded AGENTS.md"
                );
                let _ = state; // state is read-only here; we just log.
                // Memory is injected in before_model_call (when we have mutable ctx).
                // Storing it on State requires &mut State, which we don't have here.
                // v1: re-load in before_model_call each turn (cheap for short files).
            }
            Ok(None) => {
                if self.warn_if_missing {
                    tracing::warn!(
                        path = %self.memory_path,
                        "MemoryMiddleware: no AGENTS.md found at configured path"
                    );
                }
            }
            Err(e) => {
                tracing::error!(
                    path = %self.memory_path,
                    error = %e,
                    "MemoryMiddleware: failed to load AGENTS.md"
                );
            }
        }
    }

    async fn before_model_call(&self, ctx: &mut ModelRequest, _state: &State) {
        // Re-load memory each turn (cached on backend if needed).
        // v2 could cache via Arc<OnceCell<String>>.
        if let Ok(Some(content)) = self.load_memory().await {
            ctx.extend_system_suffix(format!("{}{}", self.header, content));
        }
    }

    async fn after_agent(&self, _state: &State, _final_output: &str) {
        // v1: no-op. v2 will persist memory writes via this hook.
    }
}
```

## 4. 逐行解释

### 4.1 `before_agent` 只做日志

```rust
async fn before_agent(&self, state: &State) {
    match self.load_memory().await { ... }
}
```

Middleware trait 在 `before_agent` 给出 `&State` 而非 `&mut State`。所以 memory 加载的副作用无法持久化到 state。

### 4.2 `before_model_call` 重新加载

```rust
async fn before_model_call(&self, ctx: &mut ModelRequest, _state: &State) {
    if let Ok(Some(content)) = self.load_memory().await {
        ctx.extend_system_suffix(...);
    }
}
```

每次 model_call 都重读 memory file。FilesystemBackend 的 fs::read 是相对快的；StateBackend 是 HashMap 查找（O(1)）。这是 v1 的简化策略。

### 4.3 v2 优化方向

- 在 `before_agent` 中读到内容后，存到 `Arc<Mutex<Option<String>>>` 或 `Arc<OnceCell<String>>`
- `before_model_call` 用 cached value
- `after_agent` 提供 `save_memory` API

但 v1 不做，留作后续 task。

### 4.4 `warn_on_missing`

```rust
pub fn warn_on_missing(mut self) -> Self {
    self.warn_if_missing = true;
    self
}
```

可选警告 —— 默认静默（避免日志噪音）。

## 6. 与 DeepAgents MemoryMiddleware 的差异

| 维度 | DeepAgents | ARFV1 | 原因 |
|------|------------|-------|------|
| 文件格式 | YAML frontmatter + body | 纯文本 | v1 简化 |
| 加载时机 | before_agent 一次性 | before_model_call 每次 | v1 限制 |
| Cache | SkillIndex / OnceCell | 无 | v2 |
| 持久 memory | StoreBackend | 无（仅读取） | G-30 后续 |
| cache_control | 注入 prompt cache | 无 | G-43 后续 |

---

## 7. 不破坏 ARFV1 现有优势

1. **initial_memory 兼容** — MemoryMiddleware 是补充，不是替代
2. **BackendProtocol 复用** — 直接用 11.1 的 trait
3. **Middleware 共存** — 与 FilesystemMiddleware / SummarizationMiddleware 一起用
