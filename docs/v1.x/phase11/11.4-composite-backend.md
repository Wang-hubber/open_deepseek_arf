## 1. Motivation

实际应用往往需要**多个 backend 并存**：
- `/memory/...` → StateBackend（会话级，内存）
- `/workspace/...` → FilesystemBackend（持久化到磁盘）
- `/skills/...` → StoreBackend（只读技能库，M3+）
- 其他路径 → 默认 backend（fallback）

ARFV1 当前**没有路径路由机制**——只能用单一 backend。

**本任务目标**：实现 `CompositeBackend`，根据 `BackendPath` 前缀把请求路由到对应子 backend，未匹配的走 default。

### 3.1 `src/composite.rs`

```rust
//! `CompositeBackend` — path-prefix routing backend (Phase 11 / 11.4).
//!
//! Dispatches each operation to a child backend based on `BackendPath`'s
//! longest-matching prefix. Unmatched paths fall through to a default
//! backend. Allows applications to compose state + filesystem + skills
//! backends without changing middleware code.

use std::sync::Arc;

use async_trait::async_trait;

use crate::error::BackendError;
use crate::path::BackendPath;
use crate::protocol::BackendProtocol;
use crate::types::{
    DeleteResult, EditResult, FileData, FileInfo, GlobResult, GrepMatch, GrepResult, LsResult,
    ReadResult, WriteResult,
};

/// Composite backend with path-prefix routing.
///
/// Construct via [`CompositeBackend::new`] and add routes via
/// [`CompositeBackend::with_route`]. Routes are evaluated by **longest
/// prefix first**, so order of insertion does not matter.
pub struct CompositeBackend {
    /// (prefix, child backend) pairs, kept sorted by prefix length (longest first).
    routes: Vec<(BackendPath, Arc<dyn BackendProtocol>)>,
    /// Default backend for paths that don't match any route.
    default: Arc<dyn BackendProtocol>,
}

impl CompositeBackend {
    /// Create a new `CompositeBackend` with the given default backend.
    pub fn new(default: Arc<dyn BackendProtocol>) -> Self {
        Self {
            routes: Vec::new(),
            default,
        }
    }

    /// Add a route: paths starting with `prefix` are dispatched to
    /// `child`. Returns `self` for chaining.
    ///
    /// Routes are kept sorted by prefix length (longest first), so later
    /// additions are correctly ordered relative to existing ones.
    pub fn with_route(
        mut self,
        prefix: BackendPath,
        child: Arc<dyn BackendProtocol>,
    ) -> Self {
        self.routes.push((prefix, child));
        // Sort by prefix length descending (longest first).
        self.routes
            .sort_by_key(|(p, _)| std::cmp::Reverse(p.as_str().len()));
        self
    }

    /// Resolve a `BackendPath` to `(backend, translated_path)` using the
    /// longest-matching prefix.
    ///
    /// `translated_path` is the path stripped of the matched prefix, with
    /// a leading `/` re-attached so it is a valid `BackendPath` for the
    /// child backend. For example, route `/memory`, request `/memory/foo`:
    /// → child backend, path `/foo`. Default route (no prefix): request
    /// is passed unchanged.
    pub fn resolve<'a>(
        &'a self,
        path: &'a BackendPath,
    ) -> (&'a dyn BackendProtocol, BackendPath) {
        for (prefix, child) in &self.routes {
            if prefix.is_ancestor_of(path) {
                let suffix = path
                    .strip_prefix(prefix)
                    .unwrap_or_else(|| path.as_str().to_string());
                let translated = if suffix.is_empty() {
                    // Exact match: point at the prefix itself (e.g., ls /memory).
                    prefix.clone()
                } else {
                    BackendPath::new(&format!("/{suffix}"))
                        .unwrap_or_else(|_| path.clone())
                };
                return (child.as_ref(), translated);
            }
        }
        (self.default.as_ref(), path.clone())
    }
}

#[async_trait]
impl BackendProtocol for CompositeBackend {
    async fn ls(&self, path: &BackendPath) -> Result<LsResult, BackendError> {
        let (child, translated) = self.resolve(path);
        child.ls(&translated).await
    }

    async fn read(
        &self,
        path: &BackendPath,
        offset: u32,
        limit: u32,
    ) -> Result<ReadResult, BackendError> {
        let (child, translated) = self.resolve(path);
        child.read(&translated, offset, limit).await
    }

    async fn write(&self, path: &BackendPath, content: &str) -> Result<WriteResult, BackendError> {
        let (child, translated) = self.resolve(path);
        child.write(&translated, content).await
    }

    async fn edit(
        &self,
        path: &BackendPath,
        old_string: &str,
        new_string: &str,
        replace_all: bool,
    ) -> Result<EditResult, BackendError> {
        let (child, translated) = self.resolve(path);
        child.edit(&translated, old_string, new_string, replace_all).await
    }

    async fn delete(&self, path: &BackendPath) -> Result<DeleteResult, BackendError> {
        let (child, translated) = self.resolve(path);
        child.delete(&translated).await
    }

    async fn glob(
        &self,
        pattern: &str,
        base: Option<&BackendPath>,
    ) -> Result<GlobResult, BackendError> {
        // Strategy: for each route, if `base` is under its prefix, dispatch
        // with the translated base. Otherwise query all routes and merge.
        if let Some(base) = base {
            let (child, translated) = self.resolve(base);
            return child.glob(pattern, Some(&translated)).await;
        }
        // No base — query all routes and merge results.
        let mut merged: Vec<FileInfo> = Vec::new();
        let mut truncated = false;
        // Default backend first (paths not under any prefix).
        let default_result = self.default.glob(pattern, None).await?;
        if let Some(entries) = default_result.matches {
            merged.extend(entries);
        }
        truncated |= default_result.truncated;
        // Then each route.
        for (prefix, child) in &self.routes {
            let result = child.glob(pattern, Some(prefix)).await?;
            if let Some(entries) = result.matches {
                // Re-translate paths back to absolute (prepend prefix).
                for entry in entries {
                    let new_path = if entry.path == "/" || entry.path.is_empty() {
                        prefix.as_str().to_string()
                    } else {
                        format!("{}{}", prefix.as_str().trim_end_matches('/'), entry.path)
                    };
                    let info = FileInfo {
                        path: new_path,
                        ..entry
                    };
                    merged.push(info);
                }
            }
            truncated |= result.truncated;
        }
        Ok(GlobResult {
            error: None,
            matches: Some(merged),
            truncated,
        })
    }

    async fn grep(
        &self,
        pattern: &str,
        path: Option<&BackendPath>,
        glob_filter: Option<&str>,
    ) -> Result<GrepResult, BackendError> {
        if let Some(p) = path {
            let (child, translated) = self.resolve(p);
            return child.grep(pattern, Some(&translated), glob_filter).await;
        }
        // No base path — query all and merge.
        let mut merged: Vec<GrepMatch> = Vec::new();
        let mut truncated = false;
        let default_result = self.default.grep(pattern, None, glob_filter).await?;
        if let Some(matches) = default_result.matches {
            merged.extend(matches);
        }
        truncated |= default_result.truncated;
        for (prefix, child) in &self.routes {
            let result = child.grep(pattern, Some(prefix), glob_filter).await?;
            if let Some(matches) = result.matches {
                for m in matches {
                    let new_path = if m.path == "/" || m.path.is_empty() {
                        prefix.as_str().to_string()
                    } else {
                        format!("{}{}", prefix.as_str().trim_end_matches('/'), m.path)
                    };
                    merged.push(GrepMatch {
                        path: new_path,
                        line: m.line,
                        text: m.text,
                    });
                }
            }
            truncated |= result.truncated;
        }
        Ok(GrepResult {
            error: None,
            matches: Some(merged),
            truncated,
        })
    }

    async fn delete(&self, path: &BackendPath) -> Result<DeleteResult, BackendError> {
        let (child, translated) = self.resolve(path);
        child.delete(&translated).await
    }

    async fn upload_files(
        &self,
        files: Vec<(BackendPath, Vec<u8>)>,
    ) -> Result<Vec<Result<(), BackendError>>, BackendError> {
        // Group files by resolved backend, dispatch each group, merge results.
        let mut all_results: Vec<Result<(), BackendError>> = Vec::with_capacity(files.len());
        let mut index = 0;
        for (path, _bytes) in &files {
            let (child, translated) = self.resolve(path);
            // Find consecutive files routed to the same child.
            let mut group: Vec<(BackendPath, Vec<u8>)> = Vec::new();
            let mut indices = Vec::new();
            for (i, (p, b)) in files.iter().enumerate().skip(index) {
                let (c, t) = self.resolve(p);
                if std::ptr::eq(c, child) && t.as_str() == translated.as_str() {
                    group.push((t.clone(), b.clone()));
                    indices.push(i);
                } else {
                    break;
                }
            }
            if group.is_empty() {
                // Shouldn't happen, but safety net.
                index += 1;
                continue;
            }
            let group_results = child.upload_files(group).await?;
            for r in group_results {
                all_results.push(r);
            }
            index = indices.last().copied().unwrap_or(index) + 1;
        }
        Ok(all_results)
    }
}
```

> **设计取舍**：
> - **最长前缀匹配**：避免 `/memory` vs `/memory-cache` 误路由——`is_ancestor_of` 已包含 directory-boundary 检查
> - **路径翻译**：保持子 backend 看到的路径仍是合法 `BackendPath`（以 `/` 开头）
> - **`glob` / `grep` 无 base 时合并**：默认 + 每个路由都查，结果合并时把子路径还原为绝对路径
> - **`upload_files` 按路由分组**：一次 IO 调用多文件，避免串行 await 多个 backend

## 4. 逐行解释

### 4.1 最长前缀匹配

```rust
self.routes
    .sort_by_key(|(p, _)| std::cmp::Reverse(p.as_str().len()));
```

插入时按 prefix 长度**降序**排序，第一个匹配的就是最长。无需运行期排序。

### 4.2 路径翻译

```rust
let suffix = path.strip_prefix(prefix).unwrap_or_else(...);
let translated = if suffix.is_empty() {
    prefix.clone()
} else {
    BackendPath::new(&format!("/{suffix}"))?
};
```

例子：
- prefix=`/memory`, path=`/memory/foo` → suffix=`foo` → translated=`/foo`
- prefix=`/memory`, path=`/memory` (exact) → suffix=`` → translated=`/memory`

子 backend 看到 `/foo`，对它来说 `/foo` 是它的根。

### 4.3 glob/grep 合并

无 base 时，每个 backend 都查一遍，**结果合并时还原路径**：

```rust
let new_path = format!("{}{}", prefix.as_str().trim_end_matches('/'), entry.path);
```

例子：
- prefix=`/memory`
- child 返回 `/foo.txt`
- 合并后：`/memory/foo.txt`

### 4.4 upload_files 分组

避免每个文件单独 IO 调用。按"连续路由到同一个 child"分组。一次 child upload 调用处理整组。

## 6. 与 DeepAgents CompositeBackend 的差异

| 维度 | DeepAgents | ARFV1 | 原因 |
|------|------------|-------|------|
| 路由策略 | 注册表 + dict 顺序 | 排序后最长前缀匹配 | 显式语义 |
| 路径翻译 | 相对路径 | 保留 `/` 前缀 | BackendPath 类型约束 |
| glob 合并 | dict-style merge | 按 prefix 还原 | 与 ls 对称 |
| Sandbox impl | 无 | 无（Composite 总是 file-only） | Composite 是路由层，无独立 sandbox |

---

## 7. 不破坏 ARFV1 现有优势

1. **Bus 多 runtime** — Composite 不破坏；每个子 backend 可独立
2. **Protocol DI** — 子 backend 是 `Arc<dyn BackendProtocol>`，完全可换
3. **异步优先** — 所有路由 async
