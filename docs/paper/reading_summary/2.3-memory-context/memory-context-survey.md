# 2.3 记忆与上下文：外部注入式记忆 vs 参数内化式记忆系统对比

**报告日期**：2026年6月10日
**面向章节**：论文 §2.3

---

## 摘要

为突破 LLM 上下文窗口的有限性，两大技术路径形成：**外部注入式记忆**（MemGPT、Generative Agents）与**参数内化式记忆**（PEAM、TMEM）。围绕记忆保持率、更新能力、抗干扰性、上下文占用四个维度深度对比。核心发现：

1. 外部记忆在容量、保真度、更新灵活性上占优，但依赖检索质量且占用上下文
2. 参数化记忆在上下文占用上具显著优势（零上下文调用），但更新成本高、面临灾难性遗忘
3. **最大 Gap**：目前严重缺乏对两种范式在同等条件下的直接定量对比——这是论文的核心贡献点

---

## 1. 背景

### 1.1 上下文窗口的根本局限

LLM 上下文窗口本质是有限的、易失的"短期工作记忆"。信息超出窗口即被遗忘，导致：长时程任务失败、知识更新困难、个性化体验受限。

### 1.2 两大技术路径

| | 外部注入式记忆 | 参数内化式记忆 |
|--|-------------|-------------|
| 核心思想 | 存储与计算分离 | 记忆即权重 |
| 存储位置 | 外部向量DB | 模型参数（LoRA 权重增量） |
| 调用方式 | 检索 → 注入上下文 | 直接激活（零上下文） |
| 别名 | 非参数化记忆 | 参数化记忆 |

---

## 2. 外部注入式记忆系统

### 2.1 MemGPT：操作系统启发的分层记忆

核心设计：**工作记忆（Main Context） + 存档记忆（Archival Memory）**，类比 RAM + 磁盘。

- LLM 通过"中断信号"自主管理记忆流动——自行判断何时将信息 page out 到存档，何时 page in 回工作记忆
- 实现了远超原生上下文窗口的对话和文档处理能力

### 2.2 Generative Agents：基于记忆流的社会行为模拟

斯坦福 25 个 Agent 虚拟小镇。核心是**记忆流（Memory Stream）**——按时间顺序记录所有经历的数据库。

**三因素检索策略**：`Score = α·Recency + β·Importance + γ·Relevance`
- 新近性：最近事件权重高
- 重要性：LLM 自评分（1-10）
- 相关性：向量相似性搜索

**反思机制**：周期性回顾记忆流 → 生成高层抽象总结 → 存回记忆流，形成学习闭环。

### 2.3 配套技术：上下文压缩

| 方法 | 特点 |
|------|------|
| LLMLingua (2023) | 粗到细压缩，小模型识别冗余，可压缩至 1/20 |
| LLMLingua-2 (2024) | 标记分类任务，Transformer 编码器双向建模 |
| LongLLMLingua (2024) | 长上下文专用，动态压缩比 |

---

## 3. 参数内化式记忆系统

### 3.1 核心优势与挑战

- **零上下文调用**：记忆内化为模型"本能"，不占用 context
- **高信息密度**：压缩编码存储
- **挑战**：更新成本高、灾难性遗忘、可解释性差

### 3.2 已有工作（PEAM / TMEM）

| 工作 | 时间尺度 | 机制 |
|------|---------|------|
| PEAM | 跨回合 | LoRA 增量固化技能，跨会话能力沉淀 |
| TMEM | 会话内 | 在线 SFT 更新 B 矩阵，保持早期设定 |

---

## 4. 四维度对比

| 维度 | 外部注入式（向量DB/MemGPT） | 参数化（LoRA/PEAM） |
|------|-------------------------|-------------------|
| **记忆保持率** | **高且可控**。原始信息存储，几乎无损 | 依赖模型容量。存在压缩损失和灾难性遗忘风险 |
| **更新能力** | **灵活、快速、原子化**。直接操作数据库 | 笨重、高成本。需微调流程，无法精确删除单条记忆 |
| **抗干扰性** | 检索层面干扰。记忆条目物理隔离 | **参数层面干扰**。新记忆覆盖旧参数，系统性破坏 |
| **上下文占用** | **高占用**。检索→注入→消耗窗口 | **零占用**。内化为模型能力，最核心优势 |

**根本权衡**：外部记忆用**上下文换灵活性和保真度**，参数化记忆用**更新复杂度换上下文高效利用**。

## 5. 评估基准

| 基准 | 任务 | 上下文长度 | 核心指标 |
|------|------|-----------|---------|
| LongMemEval | 信息提取、跨会话推理、知识更新、时序推理、拒答 | 115K tokens | QA Accuracy, 记忆召回率 |
| LoCoMo | 多跳QA、事件摘要、多模态对话 | 长对话 | F1/ROUGE/BLEU |

---

## 6. 关键 Gap

目前**严重缺乏**对两种范式在同等条件下的直接定量对比研究。现有工作各聚焦于自身路径优化，无统一基准下的端到端比较。这个 Gap 是论文 §2.3 和 §5.1（实验一）的核心贡献点。
