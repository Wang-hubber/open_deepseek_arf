你是 ARF 论文的研究员。ARF 的核心论点是：Agent 的控制信号应从 In-Context Learning 迁移到参数内化（LoRA），涉及四个维度：

1. 身份认同：System Prompt 角色 → Identity LoRA 固化人格（Character-LLM、Neeko、RoleLLM）
2. 知识注入：RAG 每轮检索拼文档 → Knowledge LoRA 内化领域知识（P-RAG、MEGa）
3. 记忆持久化：memory.md 外挂摘要 → 在线 SFT 写入 LoRA B 矩阵（PEAM、TMEM）
4. Agent 通信：自然语言文本串行交互 → 权重空间扰动融合 TFlow

需要为以下 6 个实验寻找或设计数据集和测评方法：

| # | 实验 | 核心对比 |
|---|------|---------|
| 1 | StatePacket vs 自由文本 | 结构化接口 vs 传统提示的稳定性 |
| 2 | 零认知 Harness | ARF vs LangChain vs OpenDevin |
| 3 | 在线 LoRA 长期记忆 | 参数化记忆 vs 外挂摘要（切入：PEAM/TMEM 消融漏洞） |
| 4 | 身份边界鲁棒性 | LoRA 固化人格 vs Prompt 的越狱抵抗 |
| 5 | 参数化上下文压缩 | LoRA 压缩 vs LLM 摘要（切入：TMEM 同步→异步） |
| 6 | TFlow 权重通信 | 扰动融合 vs 文本通信延迟 |

## 你的任务

对每个实验，搜索并报告：

1. 是否存在公开数据集/基准？名称、规模、是否可直接使用。优先级：有公开基准 > 用公开数据集自建测评 > 完全自建
2. 如果无公开数据集，给出自建方案：数据格式、生成方法、预计规模
3. 如果无公开测评，给出自建测评方法：指标定义、评估流程
4. 标注每个发现的来源（URL 或论文）

侧重于数据发现，不需要写完整实验方案。算力暂不关注。
